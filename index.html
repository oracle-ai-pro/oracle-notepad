rounded_corner

Новый интерфейс · скругления

Oracle Notepad в бета-режиме показывает три окна (Инфо · Кодинг · Core Node) со скруглениями и промежутком между панелями — окна больше не «склеиваются» в одну плиту. Так проще держать фокус: каждая зона читается отдельно, меньше визуального шума при длинном коде и чате рядом.

Чтобы отключить скругления: Настройки → тумблер «Скругления окон НОВОЕ» → Выкл. Чтобы снова включить — тот же тумблер → Вкл. После смены нужно перезапустить Notepad (обновить страницу), чтобы применить layout.

Предпочтение уже сохранено в localStorage. Осталось только перезапустить.

Лимиты использования

С 1 ноября действует разделение квот. В Notepad учитываются текст, поиск и код (без генерации картинок). При 100% 5-часовой шкалы кнопка «Отправить» блокируется до сброса. При 100% недельной — Core Node недоступен до следующей недели (отсчёт после первого 1% в новом периоде).
